# 뉴에리두 투자 비교 · 전투 계산기

젠레스 존 제로의 두 투자안을 같은 조건에서 비교하고 강공, 명파, 이상 데미지를 상세 계산하는 정적 웹 도구입니다. 원본 Google 스프레드시트의 수식과 기본값을 JavaScript로 옮겼습니다.

## 웹에서 사용

<https://doubleo-zzz.github.io/zzz-damage-calculator/>

## 제공 기능

- 투자 비교
  - 라이브 3.0 에이전트·W-엔진·디스크의 로컬 이미지 선택
  - 에이전트 60레벨 수치와 직업별 S/A급 W-엔진 프리셋
  - 같은 전투 조건에서 투자안 A/B의 대표 기대 피해와 차이 비교
  - 공격·명파·이상 계산식 전환
  - 디스크 점수 프리셋과 4세트·2세트 조합, 시네마 수치 효과 자동 반영
  - 강공·이상·명파 W-엔진 44종의 재련 R1~R5와 수치화 가능한 패시브 자동 반영
  - 치명타 확률 100%를 넘기지 않는 치확·치피·공격력 부옵 자동 배분
  - 디스크·시네마·W-엔진 조건 설정과 파티 버프 수동 보정
- 상세 계산기
  - 강공: 공격력, 방어·저항, 치명타, 피해증가, 그로기 배율
  - 명파: 체력·공격력 기반 관입력과 관입피해, 치명타, 피해증가
  - 이상: 딜러 A/B 스냅샷, 속성이상·혼돈·난류·난개 계수, 레미엘 휘광
- 입력값 자동 저장 및 기본값 복원
- 모바일·데스크톱 반응형 UI

## 로컬 실행

빌드 과정이나 외부 패키지가 필요하지 않습니다. 정적 파일 서버로 프로젝트 루트를 열면 됩니다.

```bash
python -m http.server 4173
```

그다음 `http://localhost:4173`에 접속합니다.

## Nanoka 스냅샷 갱신

투자 비교의 에이전트·W-엔진·디스크 기초 데이터와 선택 이미지는
[zzz.nanoka.cc](https://zzz.nanoka.cc/)의 라이브 3.0 자료를 확인해 저장한 로컬
스냅샷입니다. 투자 비교 카탈로그에는 프리뷰 버전 데이터가 포함되지 않습니다.
기존 상세 계산기의 원본 시트 기반 기능과 수식은 이 카탈로그 범위와 별개로
유지됩니다.

저장소 관리자가 네트워크에 연결된 Windows PowerShell 환경에서 이미지를
갱신하려면 다음 명령을 사용합니다.

```bash
npm run update:nanoka-assets
```

갱신 스크립트는 라이브 3.0으로 표시된 에이전트와 W-엔진, 라이브 3.0 디스크
이미지만 `assets/nanoka/`에 내려받고 출처 URL·해시·수집 시각을
`assets/nanoka/source-manifest.json`에 기록합니다. 스크립트 실행은 유지보수
작업이며, 배포된 계산기는 페이지를 불러오거나 계산할 때 Nanoka API 또는 외부
이미지 호스트에 요청하지 않습니다. 사용자가 문서의 외부 출처 링크를 직접
여는 경우에만 해당 사이트로 이동합니다.

## 계산 기준

계산식과 기본값은 다음 공개 스프레드시트를 기준으로 합니다.

<https://docs.google.com/spreadsheets/d/1MBIJUZt4_295LxIxvePQEFrTjmFsOu0tKPb3oPK67Tg/htmlview>

소수점이 포함된 정밀 결과를 먼저 계산한 뒤, 원본 시트와 동일하게 최종 표기 데미지는 올림 처리합니다.

딜러 A의 `감전난류`는 원본 시트의 최신 수식과 동일하게 감전 속성 피해 보너스를 참조합니다.

시네마, W-엔진과 디스크 세트 중 수치화한 효과는 선택한 단계·재련과 조건
설정에 따라 반영됩니다. 기본 비교는 지원되는 조건부 효과를 최대 발동으로
계산하며, 각 투자안에서 `조건 미발동`으로 바꿀 수 있습니다. 별도 공격 판정,
스킬 레벨 증가, 에너지·회전율처럼 현재 단일 피해식으로 안전하게 환산할 수
없는 효과는 자동 합산하지 않고 화면에 제외 사유를 표시합니다.

비교 결과는 전체 로테이션 DPS가 아니라 입력한 대표 계수 1회의 기대 피해입니다.

## 안내

이 프로젝트는 비공식 팬 제작 도구이며 HoYoverse/COGNOSPHERE 또는 Nanoka와
제휴하거나 이들의 승인을 받은 서비스가 아닙니다. Nanoka는 자료 확인 및 로컬
스냅샷 수집 경로로 표기했습니다. Zenless Zone Zero의 게임 이미지·명칭·상표를
포함한 원 저작물의 권리는 HoYoverse/COGNOSPHERE 및 각 권리자에게 있습니다.
